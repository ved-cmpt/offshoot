How it fits your organization

Inside your network. Beside your mainframe.

The reference deployment model: Offshoot runs where your code already lives, talks to the AI endpoint you have approved, and hands back C# one verified module at a time, while the mainframe keeps running until each cutover.

One module's route:

@switch (mode()) { @case ('legacy') { The mainframe answers. Nothing has changed for anyone yet. } @case ('shadow') { Both run. The mainframe still answers, and the facade records every difference. } @case ('modern') { The C# service answers, after a clean shadow sample. Rolling back is one step. } }

  • Built: the orchestrator, the sandboxes (no network, read-only sources, CPU, memory and time limits), the harness, the gates, the audit log, and a YARP facade with legacy, shadow and modern per module.
  • In v1 instead: sources come from a .zip upload or the bundled sample, not a source-control connector; the AI is the recorded fixtures or Gemini through its API; verified C# is stored with its SHA-256 and shown in the app, and is not yet opened as a pull request.
  • This is a model of how a deployment would look, not a description of any customer. Offshoot has none.
